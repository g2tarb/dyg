# DYG — Do Your Game

**One-liner:** Scan your GitHub in 10 seconds. Discover your developer archetype. Train. Ship real projects. Build a portfolio no one can ignore.

**Website:** https://dyg.dev
**Status:** Alpha — Early Access
**Built by:** 4Dayvelopment

---

## The Problem

Self-taught developers have skills but no proof. GitHub is unreadable. LinkedIn is declarative. Coding challenges are disconnected from reality. There is no platform that measures what a developer actually does and turns it into something verifiable.

---

## The Solution

DYG scans a developer's GitHub profile and generates a complete developer identity in 10 seconds:

- **7-pillar scoring** — Code, Velocity, Craft, Collaboration, Versatility, Creativity, Autonomy (1-10 scale)
- **7 archetypes** — Architect, Shipper, Artisan, Creative, Explorer, Commando, Mentor
- **Dev style detection** — Traditional, Vibe Coder, or IA Architect
- **AI-generated bio** — Based on actual code patterns, not self-declaration

---

## What Users Can Do

| Feature | Description |
